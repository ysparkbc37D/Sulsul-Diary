한 줄 요약

술술다이어리는 서버가 없습니다. 회원가입도, 로그인도 없습니다. 기록한 모든 내용은 이용자의 기기 안에만 저장되며 제작자에게 전송되지 않습니다. 제작자는 이용자의 어떤 개인정보도 수집·보관·열람하지 않습니다.

1. 수집하는 개인정보

없습니다. 이 앱은 이름·연락처·이메일·계정 등 어떤 개인정보도 요구하지 않고, 회원가입 절차 자체가 없습니다. 분석 도구(Google Analytics 등), 광고 식별자, 추적 쿠키를 일절 사용하지 않습니다.

2. 이용자가 기록한 내용은 어디에 저장되나요

이용자가 등록한 위스키 정보(제품명·구매가·구매일·구매처·테이스팅 노트·사진·평점 등)는 브라우저의 저장 영역(localStorage)에 저장됩니다. 이 영역은 이용자의 기기 안에만 존재합니다.

저장 키내용
wc.v1등록한 병 목록 전체(사진 포함)
wc.theme밝은/어두운 테마 선택
wc.view그리드/리스트 보기 선택
wc.trash전체 초기화 되돌리기용 임시 사본
wc.tab마지막에 보던 술장 탭(전체/구매/경험/위시)
wc.sync동기화를 켠 경우의 저장소 주소·경로
wc.token동기화를 켠 경우의 GitHub 접근 토큰
wc.aikeyAI 초안을 켠 경우의 본인 Google API 키 (§3-2 참고). 넣지 않으면 존재하지 않습니다
wc.aimodelAI 초안에 쓸 모델 이름

기기를 바꾸거나 브라우저 데이터를 지우면 이 내용은 사라집니다. 그래서 앱은 JSON 백업을 권장하며, 백업 파일은 이용자가 직접 보관합니다.

3. 외부로 나가는 통신

저장은 기기 안에서만 이루어지지만, 앱이 동작하는 과정에서 아래 외부 서비스와 통신합니다. 정확한 고지를 위해 전부 밝힙니다.

3-1. 이용자의 조작 없이 발생하는 통신

대상시점전달되는 것
Vercel
sulsul-diary.vercel.app		 앱을 열 때 앱 파일을 내려받기 위한 접속. Vercel 의 서버 기록에 접속 IP·브라우저 정보가 남습니다(Vercel 의 정책에 따릅니다). 제작자는 이 기록을 열람할 수 없습니다.
Wikimedia Commons
commons.wikimedia.org		 초안 생성·사진 검색 시 검색어로 위스키 이름이 전달됩니다. 구매가·구매처 등은 전달되지 않습니다.
Wikipedia
en.wikipedia.org		 초안 생성 시 증류소·제품 항목을 찾기 위한 검색어
Wikimedia
upload.wikimedia.org		 사진을 표시할 때 이미지 요청에 따른 접속 IP

초안·사진 검색을 쓰지 않고 직접 입력과 직접 촬영만으로 사용하면 2·3·4번 통신은 발생하지 않습니다.

3-2. AI 초안 — 이용자가 켜고 누를 때만 발생하는 통신

대상시점전달되는 것
Google
generativelanguage.googleapis.com		 설정에서 API 키를 넣은 뒤, 편집 화면의 AI로 빈 칸 채우기를 눌렀을 때만 위스키 이름과 채울 필드의 이름뿐입니다. 컬렉션 목록·구매가·구매처·사진·시음 기록은 전달되지 않습니다.

기본값은 꺼짐입니다. API 키를 넣지 않으면 이 통신은 전혀 발생하지 않고, 앱의 모든 기능을 그대로 쓸 수 있습니다.

  • 호출은 이용자 본인의 Google AI Studio API 키로 이루어집니다. 제작자의 서버를 거치지 않으며 제작자는 무엇을 물었는지 알 수 없습니다.
  • 키는 이 브라우저에만 저장되고 백업 파일·동기화 저장소에 포함되지 않습니다. 설정에서 지우기를 누르면 즉시 삭제됩니다.
  • Google 무료 등급은 입력한 내용이 모델 개선에 쓰일 수 있습니다. 유료 등급과 정책이 다르므로, 넣기 전에 Google 의 약관을 확인하세요.
  • 받은 값은 초안으로만 채워집니다 — 이용자가 직접 고치면 초안 표시가 사라지고, 그 뒤로는 AI 가 다시 덮지 않습니다. 사실 여부는 이용자가 라벨을 보고 확인해야 합니다.
  • 구매 가격·구입일·구입처·상태·잔량·보관 위치·내 점수는 채우지 않습니다 — 이용자 본인의 기록이기 때문입니다. (시장가와 Whiskybase 평점은 이용자 요청으로 채우되, 역시 초안 표시가 붙습니다. 메모는 덮지 않고 아래에 덧붙입니다.)

3-3. 이용자가 눌렀을 때만 발생하는 링크

아래는 새 탭으로 열리는 링크입니다. 누르지 않으면 통신하지 않습니다. 이동 후에는 해당 사이트의 개인정보처리방침이 적용됩니다.

  • Google 이미지 검색 · Google 검색 (사진 찾기, 시세 조회)
  • 네이버 쇼핑 (시세 조회)
  • Whiskybase (제품 정보 조회)
  • Notion (후원 안내 페이지)

4. 선택 기능 — GitHub 동기화

여러 기기에서 같은 목록을 보고 싶은 이용자를 위한 선택 기능입니다. 기본값은 꺼져 있고, 켜지 않아도 앱의 모든 기능을 쓸 수 있습니다.

  • 이용자가 본인의 GitHub 비공개 저장소를 지정하고, 앱이 그 저장소로 기록을 직접 올립니다. 제작자의 서버를 거치지 않으며 제작자는 그 저장소에 접근할 수 없습니다.
  • 접근 토큰은 이용자 기기의 wc.token 에만 저장됩니다. 제작자에게 전송되지 않습니다.
  • 토큰은 암호화되지 않은 상태로 저장됩니다. 기기나 브라우저 프로필에 접근할 수 있는 사람은 읽을 수 있으므로, 공용 PC 에서는 동기화를 켜지 마세요.
  • 토큰은 JSON·CSV 백업 파일에 포함되지 않습니다. 백업은 병 목록만 담습니다.

자세한 설정 방법과 주의사항은 GitHub 데이터 연동 가이드를 참고하세요.

5. 데이터의 삭제

이용자가 언제든 직접 지울 수 있습니다. 제작자가 대신 삭제할 수 있는 데이터는 애초에 존재하지 않습니다.

  • 앱 안에서 — 설정(⚙) → 전체 초기화. 실수를 막기 위해 2단계 확인을 거치며, 지운 직후에는 초기화 되돌리기로 복구할 수 있습니다.
  • 브라우저에서 — 사이트 데이터 삭제. 저장된 모든 내용이 즉시 사라집니다.
  • 동기화를 썼다면 — 본인의 GitHub 저장소에서 파일을 직접 삭제하고, 설정에서 토큰을 지운 뒤 GitHub 에서 해당 토큰을 폐기하세요.

6. 만 19세 이상 이용

이 앱은 주류 기록을 다룹니다. 만 19세 이상만 이용해 주세요. 주류의 판매·중개·광고를 하지 않으며, 이용자가 이미 보유하거나 시음한 술을 개인적으로 기록하는 도구입니다.

7. 사진과 저작권

초안 생성 시 제안되는 사진은 Wikimedia Commons에서 가져오며, 각 파일의 라이선스(CC BY-SA 등)를 따릅니다. 앱은 초안 화면에 출처 링크를 함께 표시합니다. 이용자가 직접 촬영한 사진의 권리는 이용자에게 있습니다.

8. 방침의 변경

방침이 바뀌면 이 페이지를 갱신하고 상단의 시행일을 고칩니다. 별도의 통지 수단이 없으므로(연락처를 수집하지 않기 때문입니다) 중요한 변경은 앱 안에서 안내합니다.

9. 문의

문의는 술술다이어리 블로그의 댓글로 남겨 주세요. 연락처를 수집하지 않으므로 별도의 문의 창구를 두지 않습니다.

# 🥃 Whisky Collector (PWA)

**위스키 이름만 입력하면** 사양·캐스크·테이스팅 노트·시장가·병 사진 초안을 자동으로 만들고,
필요한 부분만 고쳐 저장하는 개인 컬렉션 앱. 서버·빌드·계정 없이 동작하는 단일 페이지 PWA입니다.

---

## 1. 파일 구성

| 파일 | 역할 |
| :--- | :--- |
| `index.html` | 앱 본체 (UI · 자동 초안 · 썸네일 정규화 · CSV 입출력) |
| `kb.js` | 내장 지식 DB — **증류소 251곳** · 제품 71종 · 독립병입자 9곳 |
| `manifest.webmanifest` | PWA 설치 정보 |
| `sw.js` | 서비스 워커 — 오프라인 동작 + 병 사진 캐싱 |
| `whisky.json` | 교환·시드 데이터 (⚙️ → `whisky.json 에서 병합`) |
| `icons/` | 앱 아이콘 (192 · 512 · maskable · apple-touch) |
| `.nojekyll` | GitHub Pages의 Jekyll 처리 비활성화 |

컬렉션 데이터는 **브라우저의 localStorage**(키 `wc.v1`)에 저장됩니다.

## 2. 자동 초안 — 이름 한 줄로 등록

`＋ 추가` → 이름 입력 → `✨ 초안 자동 작성` → **평균 10~16개 항목이 채워진 폼**이 열립니다.
초안 항목은 배경이 강조되고 `초안` 배지가 붙으며, 값을 고치면 배지가 사라집니다.

### 검색이 헐렁해도 찾아냅니다 — 발음 골격 매칭

한글과 영문을 **자음 클래스 문자열**로 바꿔 비교하므로, 표기가 달라도 같은 증류소로 인식합니다.

```
글렌드로낙 · 글렌드로나크 · Glendronach  →  모두 krntrnk
라프로익   · 라프로에그   · Laphroaig    →  모두 rprk
```

* 한글이 흔히 생략하는 **음절 끝 r·묵음 h** 를 보정합니다 (`카듀`↔`Cardhu`, `워터포드`↔`Waterford`)
* `ㅈ/ㅊ`↔`j·z·ch·ts`, 영어 `c`의 경/연음, `gh` 묵음까지 규칙으로 처리합니다
* 덕분에 DB에 **한글 별칭을 넣지 않아도** 한글 입력이 잡혀, 증류소를 251곳까지 넣을 수 있었습니다
* 테스트한 50개 표기 변형·오타 전부 1순위 매칭 (`까루이자와`→Karuizawa, `컷티삭`→Cutty Sark 등)

### 입력하는 동안 추천 목록

`글렌`만 쳐도 **글렌피딕 · 글렌파클라스 · 글렌알라키 · 글렌모렌지 · 글렌리벳** 순으로 후보가 뜹니다
(테이스팅 노트·제품 데이터가 있는 증류소를 앞세움). 한 글자(`맥`→맥캘란)도 동작합니다.

추천을 탭하면 그 증류소의 **제품 라인업 칩**이 나타나고(아드벡 → `10 Year Old` `Uigeadail` `Corryvreckan`),
칩을 누르면 도수·캐스크·평점·시장가까지 채워진 초안이 바로 열립니다.

DB에 없으면 **구글 · 데일리샷 · Whiskybase 검색 링크**를 제시하고, 빈 양식에 이름만 넣어 진행합니다.

### 무엇을 어디서 가져오는가

| 항목 | 출처 | 비고 |
| :--- | :--- | :--- |
| 증류소 · 국가 · 지역 · 타입 | 내장 DB (`kb.js`) | 오프라인 동작 |
| 도수 · 숙성 · 캐스크 | 내장 DB 제품 매칭 | 제품이 없으면 증류소 기본 캐스크 |
| Nose · Taste · Finish | 내장 DB 제품 → 증류소 하우스 스타일 → 지역 일반 특성 | 3단 폴백 |
| 참고 평점 · 추정 시장가 | 내장 DB | `≈` 표기 = 참고값 |
| 병 사진 후보 | Wikimedia Commons API | 최대 8장, 탭 한 번에 적용 |
| 증류소 설명 링크 | Wikipedia API | 폼 안에 요약 표시 |
| 보틀러 | 독립병입자 감지 | IB 감지 시 주의 문구 자동 추가 |

**인식 예시** — `글렌알라키 10년 캐스크 스트렝스` · `아드벡 우거달` · `발베니 12년 더블우드` ·
`와일드터키 101` · `롱몬 23년 CS` · `시그나토리 롱몬 23년` · `Blanton's Original` · `조니워커 블루` ·
`포트엘렌` · `까루이자와` · `로얄브라클라` · `코츠월드`

> Whiskybase·주요 쇼핑몰은 공개 API가 없고 브라우저에서 직접 읽는 것이 차단(CORS)되거나 이용약관 위반입니다.
> 그래서 **합법적으로 호출 가능한 Wikipedia/Commons + 내장 DB** 조합으로 구성했습니다.
> DB에 없는 위스키는 **영문명으로 다시 입력**하거나, 폼에서 `🔄 사진 다시 찾기`를 누르세요.

## 3. 썸네일 크기 자동 맞춤

등록되는 모든 사진은 저장 시점에 **동일 규격으로 가공**됩니다.

1. 배경 여백을 픽셀 단위로 감지해 잘라냄 (흰 배경·투명 PNG·회색 배경 모두 대응)
2. **360 × 450 (4:5)** 흰 캔버스에 중앙 배치
3. **세로 기준 90%**로 배율 통일 — 가로가 넘치면 좌우 중앙 크롭, 초광각이면 폭 기준 축소

결과: 어떤 출처의 사진을 넣어도 목록의 병 크기가 들쭉날쭉하지 않습니다(실측 세로 90~92%).
장당 12~40KB로 압축되며, 기존에 등록한 사진은 ⚙️ → `등록된 사진 크기 일괄 맞춤`으로 한 번에 정리할 수 있습니다.

> 외부 사이트가 이미지 접근을 제한(CORS)하면 가공이 불가능하므로 원본을 그대로 표시하고,
> CSS로 프레임만 맞춥니다. 위키미디어 이미지는 항상 가공됩니다.

## 4. GitHub Pages 배포 (최초 1회)

### 4-1. 저장소 만들기
GitHub 웹에서 새 저장소 생성 — 이름 예: `whisky-collector`, **Public**, README 생성 안 함.

### 4-2. 이 폴더를 올리기
`LG MVP/Whisky-Collector` 폴더에서 터미널을 열고:

```bash
git init && git add . && git commit -m "Whisky Collector PWA"
```

```bash
git branch -M main && git remote add origin https://github.com/<내아이디>/whisky-collector.git && git push -u origin main
```

> Public이면 소스가 공개되지만 **컬렉션 데이터는 저장소에 올라가지 않습니다**(폰 브라우저에만 저장).
> `whisky.json`에 직접 적은 내용만 공개됩니다.

### 4-3. Pages 켜기
저장소 → **Settings → Pages** → Source `Deploy from a branch` → Branch `main` / `/ (root)` → Save.
1~2분 후 주소가 발급됩니다: `https://<내아이디>.github.io/whisky-collector/`

### 4-4. 폰에 설치
* **Android(Chrome):** 주소 접속 → 메뉴 `⋮` → **앱 설치 / 홈 화면에 추가**
* **iPhone(Safari):** 주소 접속 → 공유 `↑` → **홈 화면에 추가** (iOS는 Safari에서만 설치됩니다)

설치 후 오프라인에서도 열리고, 한 번 본 병 사진은 캐시되어 비행기 모드에서도 보입니다.

### 4-5. 이후 업데이트
```bash
git add . && git commit -m "update" && git push
```
앱을 닫고 다시 열면 새 버전이 적용됩니다. (코드·데이터 파일은 네트워크 우선으로 받아
구버전이 섞이지 않도록 처리되어 있습니다.)

## 5. 사용법

### 등록 3가지 방법

| 방법 | 절차 |
| :--- | :--- |
| **① 이름만 입력 (권장)** | `＋ 추가` → 이름 → `✨ 초안 자동 작성` → 확인·수정 → 저장 |
| **② CSV 붙여넣기** | Claude에게 받은 CSV 한 줄을 ⚙️ 입력창에 붙여넣기 → `가져오기` |
| **③ 파일 가져오기** | ⚙️ → `파일에서 가져오기` (JSON · CSV) |

**빠른 CSV 컬럼 순서 (12개)**
```
제품명,타입,도수,캐스크,구입일,구매가,현재시장가,Nose,Taste,Finish,평점,이미지URL
```
* 구매가는 `120000` · `120,000` · `12만` 모두 인식
* 현재시장가는 `90000~110000` 범위 표기 가능
* **같은 제품명이면 갱신**, 없으면 신규 추가

### 병 사진 넣는 4가지 경로
1. **후보 탭** — 초안 작성 시 자동 검색된 위키미디어 후보 중 선택 (가장 빠름)
2. **🔄 사진 다시 찾기** — 영문명·증류소를 채운 뒤 재검색
3. **URL 붙여넣기** — `🔍 구글 / Whiskybase / 네이버` 검색 → 이미지 길게 눌러 주소 복사 → 입력
4. **📷 직접 촬영** — 실물 사진 (가장 확실하고, 소장 인증 효과)

### 기타
* **검색** 이름·증류소·캐스크·지역·태그·메모 / **필터** 타입 칩, 상태, `초안 확인 필요`
* **정렬** 최근 등록·구입일·이름·평점·가격·도수
* **상세 카드** 기록 카드 형식 + `기록 카드(Markdown) 복사` / `CSV 한 줄 복사`
* **📊 통계** 보유 병수, 총 구매액, 추정 시장가, 평가 손익, 평균 평점·도수, 타입·증류소·지역 분포
* **테마** ⚙️ → 밝은/어두운 테마 전환 (기본: 밝은 테마)

## 6. 기기 간 동기화 (폰 ↔ PC)

기본 저장소는 **브라우저의 localStorage**라서 폰과 PC가 서로 다른 데이터를 봅니다.
GitHub 저장소를 데이터베이스로 연결하면 어느 기기에서 등록해도 같은 목록이 보입니다.

### 설정 (기기당 1회, 2분)

1. **데이터 저장소 만들기** — https://github.com/new → 이름 `whisky-data` → **Private** → Create
   (앱 저장소와 별개로 두어야 컬렉션 내용이 공개되지 않습니다)
2. **토큰 발급** — Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → Generate new token
   * Repository access: **Only select repositories** → `whisky-data`
   * Permissions → Repository permissions → **Contents: Read and write**
   * 만료일은 원하는 대로 (만료되면 재발급 후 다시 입력)
3. **앱에 입력** — ⚙️ → `기기 간 동기화`
   * 데이터 저장소: `ysparkbc37D/whisky-data`
   * 액세스 토큰: 발급받은 `github_pat_...`
   * `연결하고 동기화` 탭
4. **다른 기기에서도 3번만 반복** — 같은 저장소·같은 토큰을 입력하면 즉시 같은 목록이 나옵니다

### 동작 방식

동기화가 일어나는 시점은 **세 가지뿐**입니다. 주기적(타이머) 자동 동기화는 하지 않습니다.

| 시점 | 동작 |
| :--- | :--- |
| 앱을 열 때 | 원격을 읽어 병합 (다른 기기의 변경을 받아옴) |
| 병을 추가·수정·삭제할 때 | 1.5초 모아서 자동 업로드 |
| ⚙️ → `지금 동기화` | 즉시 병합 + 업로드 |

> 앱을 벗어날 때(홈 버튼·화면 잠금·탭 전환)는 **대기 중인 업로드만 밀어냅니다.**
> 새로 동기화를 유발하지 않으며, 모바일이 타이머를 정지시켜 편집 내용이 사라지는 것을 막는 처리입니다.

### 동기화가 안 될 때

헤더 **⚙️ 오른쪽 위 점**이 상태를 알려줍니다 — 🟡 진행 중 / 🟢 완료 / 🔴 실패.
실패하면 토스트 메시지가 뜨고, ⚙️ 화면 상단에 마지막 오류가 남습니다.

⚙️ → **`🔎 연결 진단`** 을 누르면 단계별로 원인을 짚어 줍니다.

| 진단 결과 | 해결 |
| :--- | :--- |
| `토큰 → ❌ 없음` | 토큰 칸에 `github_pat_...` 입력 후 저장 |
| `저장소 접근 → HTTP 401 Bad credentials` | 토큰이 잘못됨/만료 — 재발급 |
| `저장소 접근 → HTTP 404` | 저장소 이름 오타, 또는 **토큰의 Repository access에 그 저장소가 선택되지 않음** |
| `⚠ 브랜치 불일치` | 브랜치 칸을 안내된 기본 브랜치명으로 수정 |
| `⚠ 쓰기 권한` | 토큰 권한을 **Contents: Read and write** 로 재발급 |
| `원격 데이터 파일 → 아직 없음` | 정상 — `지금 동기화`를 누르면 생성됩니다 |

**두 기기 모두** ⚙️에서 같은 저장소·같은 토큰을 넣고 `연결하고 동기화`를 한 번 눌러야 합니다.
한쪽만 연결하면 그 기기에서만 업로드되고 다른 기기는 계속 로컬 데이터를 봅니다.

* **병합 규칙** — 같은 병은 `updated_at`이 최신인 쪽을 채택, 서로 다른 병은 합집합
* **삭제 전파** — 삭제 기록(툼스톤)을 남겨 다른 기기에서도 사라집니다. 삭제 후 다시 등록하면 되살아납니다
* 폰과 PC에서 **같은 병을 동시에** 고치면 나중에 저장한 쪽이 남습니다
* 커밋 이력이 그대로 남으므로 GitHub에서 **과거 상태를 언제든 되돌려 볼 수 있습니다**

### 토큰 보안

* 토큰은 **그 브라우저의 localStorage에만** 저장되고, 백업 JSON·CSV에는 포함되지 않습니다
* Fine-grained 토큰을 `whisky-data` 한 곳으로 제한하면, 유출돼도 그 저장소 밖으로는 영향이 없습니다
* 공용 PC에서는 사용 후 ⚙️ → `연결 해제`로 토큰을 지우세요

> 동기화를 켜지 않으면 앱은 지금처럼 **완전히 로컬로만** 동작합니다.

## 7. 백업 — 동기화를 안 쓴다면 꼭 읽어 주세요

로컬 저장 데이터는 다음 상황에서 사라질 수 있습니다.
* 브라우저 데이터/캐시 삭제, 사이트 데이터 정리
* 기기 변경, 다른 브라우저로 열기 (브라우저마다 별도 저장)
* iOS: 장기간 미사용 시 시스템이 저장 공간을 정리할 수 있음

**병을 추가한 날에는** ⚙️ → `전체 백업 (JSON · 사진 포함)`으로 파일을 받아 두세요.
복구는 ⚙️ → `파일에서 가져오기`. 엑셀·구글시트로 보려면 `전체 CSV`를 쓰세요.
(동기화를 켜면 GitHub 저장소가 사실상 자동 백업 역할을 합니다.)

## 9. 참고 · 주의

* 기본 6병은 **사용 예시**입니다. ⚙️ → `예시 데이터 삭제`로 정리하세요.
* **초안은 초안입니다.** 평점(`≈`)·시장가는 참고값이고, Whisky Bible 점수는 판본마다 다릅니다.
  실제 라벨·영수증·현재 시세로 확인해 수정하세요. 확인 전 항목은 목록에 `초안` 배지로 남습니다.
* **배치물·캐스크 스트렝스·독립병입(IB)** 제품은 병마다 도수·캐스크가 달라, 앱이 자동으로 경고 메모를 넣습니다.
* `평가 손익`은 입력한 구매가와 추정 시장가의 차이로, 수수료·세금·실거래를 반영하지 않은 참고 지표입니다.
* 위키미디어 사진을 쓰면 출처가 자동 기록됩니다(상세 카드에 표시). Commons에 병 사진이 없는 증류소는
  증류소 건물 사진이 후보로 나올 수 있으니 직접 촬영을 권합니다.

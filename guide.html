사용 가이드

이름만 입력하면 초안이 채워지는 개인 위스키 기록장

이 페이지는 오프라인용 요약입니다

인터넷이 연결돼 있다면 그림과 예시가 있는 블로그 사용 가이드를 보세요. 이 페이지는 앱에 저장되어 비행기 모드에서도 열립니다.

이 앱의 사용법을 한 문단으로

＋ 추가를 누르고 위스키 이름만 적습니다. 타입·증류소·캐스크·테이스팅 노트 초안이 자동으로 채워지고 사진 후보까지 제안됩니다. 틀린 부분만 고쳐서 저장하면 끝입니다. 기록은 내 기기에만 저장되니 가끔 JSON 백업만 받아 두세요.

1. 앱으로 설치하기

브라우저로도 쓸 수 있지만, 설치하면 세 가지가 좋아집니다 — 주소창 없이 전체화면으로 열리고, 오프라인에서도 동작하고, 저장한 기록이 보호됩니다 (브라우저가 저장 공간을 정리할 때 지우지 않습니다).

  1. iPhone · iPad 사파리에서 열고 아래쪽 공유 버튼(↑) → 목록을 내려 홈 화면에 추가 → 오른쪽 위 추가. 아이폰은 이 방법만 가능합니다.
  2. Android 크롬 메뉴 → 앱 설치 또는 홈 화면에 추가. 설정(⚙) 안의 홈 화면에 추가 버튼을 눌러도 됩니다.
  3. PC (크롬 · 엣지) 주소창 오른쪽의 설치 아이콘, 또는 메뉴 → 앱 설치. 작업표시줄에 고정해 두면 프로그램처럼 쓸 수 있습니다.

2. 병 등록하기

  1. 이름을 적습니다 ＋ 추가 → 이름 칸에 글렌드로낙 15 처럼 적습니다. 한글 표기로도 찾습니다 — 아벨라워아부나흐, 쿨일라, 맥캘란 모두 인식합니다. 붙여 써도 됩니다.
  2. 초안을 확인합니다 타입·국가·증류소·캐스크·도수·테이스팅 노트·평점이 채워집니다. 자동으로 채운 칸에는 초안 표시가 붙고, 그 칸을 고치면 표시가 사라집니다.
  3. 구매 정보를 넣습니다 구매가·구매일·구매처는 자동으로 알 수 없으니 직접 넣습니다. 나중에 통계와 시세 비교에 쓰입니다.
  4. 저장합니다 사진이 있으면 자동으로 3:4 규격에 맞춰집니다.
초안 표시는 "확인이 필요하다"는 뜻입니다

초안은 내부 데이터와 위키백과를 조합한 추정치입니다. 특히 단일 캐스크·캐스크 스트렝스·면세판처럼 병마다 값이 다른 제품은 도수와 평점이 실제 라벨과 다를 수 있습니다. 라벨을 보고 확인해 주세요.

3. 사진 넣기

  • 사진 다시 찾기 — 위키미디어에서 후보를 다시 검색합니다.
  • 직접 촬영 — 가장 정확합니다. 내 병의 실제 모습이 남습니다.
  • 이미지 URL — 주소를 붙여 넣어 추가합니다.
  • 구글 · 네이버 · Whiskybase — 새 탭에서 찾아본 뒤 이미지 주소를 가져옵니다.

한 병에 최대 5장까지 넣을 수 있고, 첫 장이 대표 사진이 됩니다. 사진을 탭하면 대표로 지정되고, 다시 탭하면 삭제됩니다. 상세 화면에서 사진을 탭하면 크게 볼 수 있습니다.

4. 카드 읽는 법

모든 카드는 정확히 네 줄로 같은 자리에 같은 정보를 보여줍니다.

사진 위의 표식

왼쪽 위에는 경험 · 위시 · 초안이, 오른쪽 위에는 상태와 19세 표기가 붙습니다.

미개봉 — 아직 열지 않은 병. 잔량 100%
오픈 — 마시고 있는 병. 기록한 잔량이 바에 표시됩니다
비움 — 다 마신 병. 잔량 0%
경험 — 보유하지 않았지만 마셔 본 병. 바는 비어 있고 —
위시 — 사고 싶은 병. 바는 비어 있고 —
19 19세 이상 이용 — 주류를 다루므로 모든 카드에 붙습니다

5. 찾기와 정렬

  • 검색 — 제품명·증류소·캐스크·태그를 함께 찾습니다.
  • 주종 탭 — 위스키 · 와인 · 리큐르 · 기타주류. PC 에서는 왼쪽 사이드바에 있습니다.
  • 타입 칩 — 고른 주종 안에서 Single Malt, Bourbon 등으로 좁힙니다.
  • 필터 — 상태 · 숙성년수 · 맛 프로필(피트 · 셰리 · 과일 · 버번 · 와인 · 라이).
  • 정렬 — 최근 등록 · 구입일 · 이름 · 평점 · 가격 · 도수 · 잔량 · 개봉일.
  • 보기 전환 — 오른쪽 버튼으로 그리드 ↔ 리스트. 병이 많으면 리스트가 빠릅니다.

6. 마시면서 기록하기

  • 개봉 처리 — 상세 화면에서 누르면 상태가 오픈으로 바뀌고 개봉일이 남습니다.
  • 잔량 — 남은 양을 %로 적으면 카드의 4번째 줄 바에 반영됩니다.
  • 시음 기록 — 마신 날의 인상을 여러 번 쌓을 수 있습니다. 같은 병이 시간에 따라 어떻게 변하는지 남습니다.
  • 통계 — 상단 그래프 버튼. 보유 현황, 주종·타입 분포, 구매 합계, 시세 대비 평가 손익을 봅니다.

7. 백업 — 꼭 읽어 주세요

기록은 이 기기에만 있습니다

기기를 바꾸거나 브라우저 데이터를 지우면 사라집니다. 서버에 사본이 없으므로 복구해 드릴 수 없습니다. 병을 여러 개 등록했다면 지금 백업을 받아 두세요.

설정(⚙) → 데이터에서:

  • 전체 백업 (JSON) — 사진까지 포함한 완전한 사본입니다. 이것이 기본 백업 수단입니다. 다시 불러오면 그대로 복원됩니다.
  • 전체 CSV — 엑셀·구글시트에서 열어 보거나 가공할 때 씁니다. 사진은 포함되지 않습니다.
  • 요약 CSV 복사 — 12개 항목만 클립보드로 복사합니다.

불러오기는 제품명으로 맞춥니다 — 같은 이름은 갱신하고 새 이름은 추가합니다.

여러 기기에서 같은 목록을 보고 싶다면

기본 기능은 기기 저장 + JSON 백업입니다. 폰과 PC 에서 자동으로 같은 목록을 보려면 선택 기능인 GitHub 동기화를 켤 수 있습니다. 무료이며, 본인의 비공개 저장소를 씁니다. → GitHub 데이터 연동 가이드

8. 안전장치

  • 전체 초기화는 2단계 확인을 거칩니다. 지운 직후에는 초기화 되돌리기로 복구할 수 있습니다.
  • 폰에서 뒤로 가기를 눌러도 앱이 바로 닫히지 않습니다.
  • 설정에 저장소 보호 상태가 표시됩니다. 꺼져 있으면 앱으로 설치해 주세요.

9. 자주 묻는 것

이름을 넣었는데 못 찾습니다

표기를 조금 바꿔 보세요(글렌드로낙 ↔ 글렌드로낙 15년). 그래도 안 되면 직접 입력해도 됩니다 — 초안은 편의 기능일 뿐 필수가 아닙니다.

도수가 비어 있습니다

단일 캐스크·캐스크 스트렝스는 병마다 도수가 달라 일부러 추측하지 않습니다. 라벨을 보고 넣어 주세요.

사진이 병 대신 증류소 풍경입니다

위키미디어에 그 제품의 병 사진이 없는 경우입니다. 직접 촬영을 권합니다.

오프라인에서도 되나요

됩니다. 앱과 사진이 기기에 저장되어 있어 비행기 모드에서도 열립니다. 다만 새 초안 생성과 사진 검색은 인터넷이 필요합니다.

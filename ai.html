Sulsul Diary 술술다이어리

AI 초안 안내

이름만 넣으면 사양 초안을 채워 주는 선택 기능 · 본인 API 키 · 기본은 꺼짐

먼저 — 이 기능은 없어도 됩니다

술술다이어리는 내장 데이터(증류소 295곳)와 위키백과로 이미 초안을 채웁니다. AI 초안은 그것으로 부족할 때 빈 칸만 더 채우는 보조 수단입니다.

키를 넣지 않으면 이 기능과 관련된 통신은 전혀 발생하지 않고, 앱의 모든 기능을 그대로 쓸 수 있습니다.

1. 무엇이 전달되나요

전달되는 것전달되지 않는 것
위스키 이름
채울 필드의 이름(예: 증류소, 지역, 캐스크)		 컬렉션 목록 · 구매가 · 구매처 · 사진 · 시음 기록 · 평점 · 보관 위치 · 잔량

호출은 이용자 본인의 API 키로 이루어집니다. 제작자의 서버를 거치지 않으며 제작자는 무엇을 물었는지 알 수 없습니다.

Google 무료 등급은 입력이 모델 개선에 쓰일 수 있습니다

무료 등급과 유료 등급의 정책이 다릅니다. 키를 넣기 전에 Google 의 약관을 한 번 읽어 보세요. 위스키 이름 외에는 나가지 않지만, 무엇이든 나가는 것이 싫다면 이 기능을 켜지 않는 것이 맞습니다.

2. 키 발급과 설정

  1. Google AI Studio 에서 키를 만듭니다 aistudio.google.com/apikey — 구글 계정으로 로그인해 Create API key 를 누릅니다. 무료입니다.
    프로젝트 이름을 복사하지 마세요 — 가장 흔한 실수입니다

    목록에는 프로젝트 이름과 API 키가 나란히 있습니다. 프로젝트 이름은 gen-lang-client-0000000000 처럼 생겼고 26자입니다. 이걸 넣으면 API key not valid 가 납니다.

    필요한 것은 API 키 열의 값입니다 — 가려져 있으니 눌러서 복사하세요. 보통 AIza… 로 시작하는 39자 또는 AQ.… 로 시작하는 더 긴 문자열입니다.

  2. 앱 설정에 붙여넣습니다 설정(⚙) → AI 초안 → Google AI Studio API 키 칸에 붙여넣고 키·모델 저장을 누릅니다.
  3. 연결 확인 같은 화면의 연결 확인을 누르면 실제 호출을 한 번 해 봅니다. 실패하면 Google 이 보낸 오류 문구를 그대로 보여 주므로 원인을 알 수 있습니다.
  4. 쓰는 곳은 편집 화면입니다 초안으로 만든 병의 편집 화면에 들어가면 위쪽에서 “확인이 필요한 칸이 n개 있습니다. AI로 다시 채워 볼까요?” 라고 먼저 묻습니다. 지금 채우기 또는 나중에 를 고르면 됩니다 — 나중에 골라도 왼쪽 버튼으로 언제든 채울 수 있습니다.
    이미 확인을 끝낸 병에서는 묻지 않습니다.

키는 이 브라우저에만 저장됩니다. 백업(JSON) 파일과 동기화 저장소에는 포함되지 않으므로, 기기마다 한 번씩 넣어야 합니다. 설정에서 지우기를 누르면 즉시 삭제되고 기능이 꺼집니다.

3. 무엇을 채우고, 무엇을 채우지 않나요

채웁니다 (초안으로)채우지 않습니다
영문명 · 타입 · 증류소 · 국가 · 지역 · 도수 · 숙성 · 캐스크 · 보틀러 · 용량 · 향 · 맛 · 여운 · 맛 프로필 · 태그 · 시장가 하단/상단 · Whiskybase 평점 · 메모(덧붙임) 구매 가격 · 구입일 · 구입처 · 내 점수 · Whisky Bible · 상태 · 개봉일 · 잔량 · 보관 위치

채우지 않는 쪽은 이용자 본인의 기록입니다 — 얼마에 샀는지, 어디서 샀는지, 지금 얼마 남았는지는 AI 가 알 수 없습니다. 보관 위치는 새 병을 만들 때 자동으로 집 이 됩니다(AI 가 아니라 기본값입니다).

시장가와 Whiskybase 평점은 특히 확인하세요

도수가 틀리면 라벨을 보고 알아챌 수 있습니다. 그런데 시장가가 틀리면 어느 화면에도 이상으로 나타나지 않습니다 — 그러면서 평가 손익, 가성비순 정렬, 위시 술장의 예상 지출이 모두 그 값에서 계산됩니다. Whiskybase 평점도 평점순 정렬과 평균 평점에 들어갑니다.

앱은 원화 5천원~1억 범위를 벗어난 값과 100점 척도를 벗어난 평점은 버립니다. 그래도 그럴듯한 범위의 틀린 값은 걸러낼 수 없습니다 — 이 두 항목은 저장 전에 한 번 눌러 확인하시는 편이 좋습니다.

4. 값을 그대로 믿지 마세요

AI 는 검색을 하지 않고 기억으로 답합니다. 그래서 그럴듯하지만 틀린 값이 나올 수 있습니다. 그 때문에 이 기능은 이렇게 만들어져 있습니다.

  • AI 가 채운 칸에는 초안 · AI 표시가 붙습니다. 그 칸을 직접 고치면 표시가 사라집니다 — 표시가 남아 있다면 아직 확인하지 않은 값입니다.
  • 채우는 대상은 빈 칸과 아직 초안 인 칸입니다. 직접 고친 칸은 덮지 않습니다.
    내장 데이터에 없는 병은 초안 엔진이 비슷한 이름의 다른 병 값을 넣어 두는 경우가 있어서, 그렇게 들어간 값도 다시 물어볼 수 있게 했습니다.
  • 되돌리기 버튼으로 방금 채운 값을 원래대로 돌립니다 — 초안 엔진이 넣어 둔 값을 AI 가 덮었다면 그 값으로 돌아가고, 원래 비어 있었으면 비워집니다. 그중 직접 고친 칸은 건드리지 않습니다.
  • 메모는 덮지 않고 아래에 덧붙입니다. 초안 엔진이 메모에 넣은 ⚠ 캐스크 스트렝스… 같은 경고가 지워지면 안 되기 때문입니다. 같은 문장은 두 번 넣지 않습니다.
  • 규격에 맞지 않는 값(목록에 없는 타입, 도수 150% 같은 값)은 앱이 버립니다.
  • 대조가 필요하면 편집 화면의 Whiskybase · 구글 · 네이버 버튼으로 바로 검색할 수 있습니다. 출처 링크는 AI 에게 받지 않습니다 — 지어낸 링크가 확인된 것처럼 보이는 쪽이 더 위험하기 때문입니다.
